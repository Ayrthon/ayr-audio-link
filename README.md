# AYR Audio Link (releases)

This GitHub repository publishes **installers only** for [AYR Audio Link](https://ayrthon.com).

- **Download the latest Windows installer** from [**Releases**](https://github.com/Ayrthon/ayr-audio-link/releases/latest).
- Application **source code is not hosted here** (private development).

The in-app updater in AYR Audio Link checks this repo’s **Releases** feed on GitHub.
